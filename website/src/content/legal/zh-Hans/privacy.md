## 第1条 适用范围

1.1 本隐私政策（以下简称"本政策"）适用于 AuraCalc（以下简称"本应用"或"我们"）通过 Apple App Store 向用户提供的全部产品及服务。

1.2 本政策适用于本应用在 macOS、iOS 及 iPadOS 平台上的所有版本。若本应用后续新增功能模块涉及个人信息处理，我们将更新本政策并在应用内或本页面发布通知。

1.3 本政策不适用于 Apple Inc. 及其服务的隐私规则，相关事项请查阅 Apple 隐私政策。

## 第2条 术语定义

2.1 **个人信息**：以电子或者其他方式记录的能够单独或者与其他信息结合识别特定自然人身份或反映特定自然人活动情况的各种信息。

2.2 **敏感个人信息**：一旦泄露或者非法使用，容易导致自然人人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别信息、宗教信仰信息、医疗健康信息、金融账户信息、行踪轨迹信息等。

2.3 **用户内容**：用户在使用本应用过程中输入、生成或存储的数据，包括计算表达式、计算结果、历史记录、自定义常数与公式等。

## 第3条 个人信息收集

3.1 **身份信息**：本应用不要求用户注册账号，不收集姓名、电子邮件地址、电话号码、身份证号等个人身份信息。

3.2 **设备标识符**：本应用不收集广告标识符（IDFA）、供应商标识符（IDFV）、设备序列号或任何可跨应用追踪用户的设备标识符。

3.3 **位置信息**：本应用不请求、不收集精确位置或粗略位置信息。

3.4 **生物识别信息**：本应用不收集指纹、面容等生物识别数据。

3.5 **使用行为数据**：本应用不集成任何用户行为分析或遥测系统，不收集应用使用时长、功能点击频率、屏幕浏览路径等行为数据。

3.6 本条声明覆盖本应用自身代码的全部信息收集行为。本应用所依赖的 Apple 系统框架在履行其功能时可能按照 Apple 自身隐私规则处理必要信息，此类处理不在本政策管辖范围内。

## 第4条 用户内容的存储与处理

4.1 **本地存储**：用户内容默认存储于用户设备本地，使用 SwiftData 数据库（结构化数据）及 UserDefaults（配置偏好）作为存储机制。本应用不将用户内容上传至任何由我们运营或控制的服务器。

4.2 **存储内容范围**：

- 计算表达式及对应结果（历史记录，SwiftData）
- 用户偏好设置（主题、字体、精度、语言等，UserDefaults）
- 用户自定义常数及自定义公式（UserDefaults）
- 记忆功能存储值（MS/MR/MC/M+/M-，UserDefaults）
- 已提交表达式历史（最近 50 条，UserDefaults）

4.3 **数据保留**：用户内容在本应用存续期间持续保留于设备本地，除非用户主动删除（通过删除历史记录、清屏等操作）或卸载本应用。

4.4 **数据删除**：用户可随时通过本应用内操作删除特定用户内容。卸载本应用将清除设备上本应用的全部本地数据。

## 第5条 系统集成与用户内容共享

本应用已集成以下 Apple 系统功能，这些功能会将部分用户内容传递至系统层或其他设备。所有传递均由 Apple 系统框架完成，我们无法独立控制其传输过程或获取传输数据。

5.1 **Spotlight 索引**：本应用将历史计算快照的表达式及结果索引至 Apple Spotlight 搜索系统，以便用户通过系统搜索快速查找历史计算。索引内容包括表达式文本、计算结果及关键词。用户可在系统"设置 → Siri 与搜索"中关闭本应用的 Spotlight 搜索权限。

5.2 **Handoff**：本应用支持 Apple Handoff 功能，可将当前计算活动（含表达式文本）在同一 Apple 账户下的不同设备间传递，以便用户在另一设备上继续操作。Handoff 数据传输由 Apple 系统框架处理，我们无法访问传输中的数据。

5.3 **Siri 快捷指令**：本应用通过 App Intents 框架向 Siri 提供两个快捷指令："计算表达式"与"单位换算"。用户通过 Siri 执行指令时，所输入的表达式仅在设备本地计算，不发送至我们的服务器。用户可在系统"设置 → Siri 与搜索"中管理本应用的 Siri 权限。

5.4 **桌面小组件（Widget）**：本应用提供桌面小组件，显示用户最近一次计算的表达式及结果。小组件通过 App Group 共享容器（UserDefaults）读取该数据，共享范围仅限上述两个字段，不包含其他用户内容。用户可在系统设置中移除小组件。

5.5 **实时活动（Live Activity）**：本应用在 iOS 端支持实时活动，可在锁屏界面显示当前计算的表达式及结果。实时活动数据由系统框架管理，我们无法远程获取。

5.6 **深度链接**：本应用注册 `auracalc://` URL Scheme，支持通过 URL 直接跳转至指定页面（如 `auracalc://history`）。URL Scheme 不携带用户内容，仅用于页面导航。

## 第6条 第三方服务

6.1 **分析服务**：本应用不集成 Google Analytics、Firebase Analytics、Mixpanel 或任何其他用户行为分析服务。

6.2 **广告服务**：本应用不集成任何广告 SDK 或广告追踪框架，不展示广告，不参与个性化广告投放。

6.3 **社交服务**：本应用不集成社交登录、社交分享 SDK 或任何第三方社交平台接口。

6.4 **汇率数据**：本应用的货币转换功能从公开汇率 API 获取汇率数据。该请求不携带任何用户个人信息或设备标识符，仅传递货币代码参数。获取的汇率数据在设备本地缓存 12 小时，离线时使用缓存数据。

6.5 若本应用后续引入新的第三方服务，我们将更新本政策并明确说明该服务的隐私影响及用户选择权。

## 第6A条 第三方软件组件（SDK）列明

依据《移动互联网应用程序信息服务管理规定》及《个人信息保护法》要求，本应用使用的第三方软件组件（SDK）列明如下：

| SDK 名称 | 来源 | 版本 | 用途 | 收集数据类型 | 数据用途 |
|----------|------|------|------|--------------|----------|
| Defaults | sindresorhus（开源） | v9.0.9 | 类型安全 UserDefaults 封装，用于读写用户偏好配置 | 无 | 仅封装系统 UserDefaults API，不额外收集数据 |
| swift-async-algorithms | Apple（开源） | v1.1.5 | AsyncChannel 与 debounce 防抖管道，用于输入节流 | 无 | 纯算法库，不收集任何数据 |
| swift-collections | Apple（开源） | v1.5.1 | Deque 双端队列，用于撤销/重做栈的高效操作 | 无 | 纯数据结构库，不收集任何数据 |

以上组件均为开源库，不集成广告、分析、追踪或任何数据上报功能，不收集用户个人信息。

## 第6B条 系统 API 使用说明

本应用使用的 Apple 系统 API 及其用途说明如下：

| API 类别 | 用途 | 是否关联用户 |
|----------|------|--------------|
| UserDefaults | 存储用户偏好设置（主题、精度、语言等）及非敏感应用数据 | 否 |
| FileTimestamp | 访问文件时间戳，用于 SwiftData 数据库文件管理 | 否 |
| SystemBootTime | 获取系统启动时间，用于计算缓存有效期 | 否 |
| Keychain | 访问 Keychain，用于 StoreKit 2 内购交易验证与订阅状态存储 | 否 |
| Network | 发起网络请求，用于货币转换功能获取公开汇率数据 | 否 |
| ActiveKeyboards | 获取当前活跃键盘信息，用于输入体验适配 | 否 |

以上 API 使用均已在 Apple 隐私清单（PrivacyInfo.xcprivacy）中声明，不用于追踪用户或关联用户身份。

## 第7条 数据安全措施

7.1 本应用运行于 Apple App Sandbox 环境，遵循 Apple 平台安全架构，应用进程仅能访问其沙盒目录内的文件及系统授权的资源。

7.2 iOS 端启用 Data Protection（NSFileProtectionComplete），设备锁定时应用数据文件受硬件密钥加密保护。macOS 端依赖 App Sandbox 沙盒隔离及用户可选的 FileVault 全盘加密。

7.3 本应用不请求以下系统权限：定位服务、通讯录、相册、相机、麦克风、健康数据、HomeKit、蓝牙。

7.4 尽管我们采取了上述合理安全措施，但任何技术手段均无法实现绝对安全。我们不对因不可抗力、系统漏洞或超出我们控制范围的因素导致的数据泄露承担绝对保证责任，但承诺在发现安全事件后及时采取补救措施并告知用户。

## 第8条 未成年人保护

8.1 本应用不面向未满 14 周岁的未成年人，亦不专门收集未成年人的个人信息。若您是未满 14 周岁的未成年人，请在监护人指导下使用本应用。

8.2 若我们发现无意中收集了未满 14 周岁未成年人的个人信息，将在核实后立即删除相关信息，并通知其监护人。

## 第9条 用户权利

9.1 **知情权**：用户有权通过本政策了解本应用对个人信息的处理规则。

9.2 **删除权**：用户可随时通过本应用内操作或卸载本应用，删除设备上存储的全部用户内容。

9.3 **系统功能控制权**：对于第5条所述的系统集成功能（Spotlight、Handoff、Siri、Widget、Live Activity），用户可在系统设置中逐项开启或关闭，不受本应用控制。

9.4 **响应时效**：对于用户依据本条提出的合理请求，我们将在收到请求后 15 个工作日内予以回复。

10.1 我们保留对本政策进行修订的权利。修订后的政策将在本页面发布，并更新版本号及生效日期。

10.2 若修订后的政策扩大了个人信息的收集范围或改变了个人信息的使用目的，我们将在修订生效前通过以下一种或多种方式通知用户：（1）应用内弹窗提示；（2）本页面标注更新内容摘要。

10.3 修订后的政策自生效日期起适用。用户在政策修订后继续使用本应用，视为接受修订后的政策内容。
